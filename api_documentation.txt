----------------------------------------
API 3: GET /api/stations/nearest/[longitude]/[latitude]
Purpose: Get nearest water stations based on location

Example:
  GET /api/stations/nearest/73.12536/19.2570744

Response (200 OK):
{
  "success": true,
  "data": [
    {
      "station_id": "RJ_JAIPUR_CHOMU_001",
      "location": {
        "village": "Chomu",
        "district": "Jaipur"
      },
      "distance_km": 2.5,
      "current_water_level": {
        "depth_m": 12.5,
        "status": "SAFE"
      }
    }
  ]
}

Errors:
  400 - Invalid coordinates
  404 - No stations found nearby
  500 - Server error

----------------------------------------
API 4: POST /api/extraction_limit
Purpose: Calculate safe water extraction limits

Request:
  POST /api/extraction_limit
  Content-Type: application/json
{
  "station_id": "RJ_JAIPUR_CHOMU_001",
  "population": 5000,
  "agricultural_area_hectares": 100
}

Response (200 OK):
{
  "success": true,
  "extraction_limit": {
    "daily_limit_m3": 150,
    "monthly_limit_m3": 4500,
    "recommended_borewells": 3,
    "status": "within_safe_limits"
  }
}

Errors:
  400 - Missing required fields
  500 - Calculation error

----------------------------------------
API 5: GET /api/future_condition
Purpose: Forecast water conditions for next 3-4 months

Request:
  GET /api/future_condition?station_id=RJ_JAIPUR_CHOMU_001

Errors:
  400 - station_id required
  404 - Station not found
  500 - Prediction model error

QUICK USAGE EXAMPLES:

// Fetch station details
const station = await fetch('/api/stations/by-id/RJ_JAIPUR_CHOMU_001')
  .then(res => res.json());

// Get AI recommendations
const recommendations = await fetch('/api/ai/RJ_JAIPUR_CHOMU_001')
  .then(res => res.json());

// Find nearest stations
const nearby = await fetch('/api/stations/nearest/73.12536/19.2570744')
  .then(res => res.json());

Base URL: http://localhost:3000
Note: All responses are in JSON format. AI recommendations may take 2-5 seconds.
